📱 Project Overview
This project explores a digital communication solution designed to support non-verbal children on the autism spectrum by making daily communication easier, clearer, and more accessible.
The idea is inspired by real-world challenges observed during field research and interviews with speech therapists and rehabilitation specialists. 
Many children understand their surroundings well but struggle to express their needs verbally, which often leads to frustration, crying, or tantrums. 
This project aims to reduce that gap through a simple, intuitive digital interface.

🔍 Research & Insights
The project is grounded in real user research, including:
Interviews with rehabilitation centers and speech specialists
Observations and testing with children
Analysis of traditional alternative communication methods (e.g. PECS)
Key findings showed that physical communication cards can be difficult to carry, easy to lose, and hard to manage in daily life. Digital tools offer a more practical and scalable alternative.

🎨 Design Approach
The interface was designed with:
Large, clear visual elements
Simple navigation and structured categories (e.g. food, family, daily needs)
Minimal cognitive load
Right-to-left layout support for Arabic users
The focus was on clarity, consistency, and accessibility rather than visual complexity.

🧑‍💻 Development
Built using SwiftUI
Modular and scalable structure
Designed to support future features such as:
Audio playback
Image attachment
Custom card creation
At this stage, the project focuses on UI and user experience, with functionality to be expanded incrementally.
